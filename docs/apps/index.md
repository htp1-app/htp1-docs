# Apps

Apps built by the HTP-1 community that talk to your unit over the network. None of these are
Monoprice products — they are made by owners, and they work because the HTP-1 exposes a control
interface on your local network.

!!! note
    Apps listed here are third-party software. They are not supplied or supported by Monoprice, and
    they are listed because members of the community built and use them. Each one links to its own
    source code, so you can see what an app does before pointing it at your hardware.

## HTP-1 Native Controller (iOS)

A native iOS remote for the HTP-1. It gives you the everyday controls — volume, input selection,
upmixer, and modes — from an iPhone, without loading the full web interface in a browser.

The app is **open source**, and the complete source is on GitHub, so you can read it, build it
yourself, or contribute.

[:material-github: View the source on GitHub](https://github.com/htp1-app/htp1-native-controller){ .md-button }

### Requirements

- An iPhone or iPad on the same network as your HTP-1
- The HTP-1's IP address, shown on the front panel **Help** screen (tap the **?** icon in the top
  right)

### Reporting problems

Issues with the app belong in its own repository, rather than with Monoprice support or the
documentation repository:

[:material-bug: Report an issue](https://github.com/htp1-app/htp1-native-controller/issues){ .md-button }

## Adding your app

Built something for the HTP-1? Open an issue on the
[documentation repository](https://github.com/htp1-app/htp1-docs/issues) with a link to the project
and a short description, and it can be listed here.
