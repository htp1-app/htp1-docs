# The Nature of the Project

## A Community-Driven Project Developing the Latest Firmware Updates

The HTP-1's code is relatively open, and that openness turned into an opportunity. A team of
programmers and testers took up the unit's software as a passion project, and they continue to
deliver fixes and improvements.

Substantial capabilities described in this manual arrived this way, in software, on units that
owners already had in their racks:

- Dirac Live **Active Room Treatment** support, alongside Bass Control and Bass Management
- The **Seat Shaker** output, with its own content routing, filtering, PEQ, and presets
- **Channel Levels**, a per-channel trim stage
- A redesigned front panel touchscreen
- **Peak Monitor** as a page of its own, and an independent **Mix Out** volume

An HTP-1 running current software is meaningfully a different machine from one running the software
it shipped with.

## What This Means for You

A few practical consequences follow from a product that improves after purchase:

- **The original documentation goes stale.** The printed and PDF manuals describe the unit as it
  was. Where this guide and older documentation disagree, this guide is written against current
  software.
- **Old advice outlives the problem it solved.** Workarounds circulate for years after the
  underlying bug is fixed. Setup steps you find elsewhere may be solving a problem your unit no
  longer has — the gigabit Ethernet DHCP issue described in
  [Basic Setup](basic-setup.md) is a good example.
- **Improvements arrive when they are ready.** There is no fixed release calendar.

## Many Builds Are in the Field

Updates are installed by owners, not pushed automatically. As a result, units in the wild run a
very wide range of software versions, and some have never been updated at all. A unit bought used,
or one that has been powered off for a long stretch, can be several years behind.

If you are unsure what you have, [System Status](system-status.md) shows the version currently
running. Updating is straightforward and preserves your settings and calibrations — see
[Updates and Support](maintenance.md).

## Where the Project Is Discussed

The [Official Monoprice Monolith HTP-1 Owners Thread](https://www.avsforum.com/threads/the-official-monoprice-monolith-htp-1-owners-thread.3112176/)
on the **AVS Forum** is the primary source of news about the project. New releases, the reasoning
behind changes, problem reports, and work in progress are all discussed there, and it is where the
people building the software talk with the people using it. If you want to know what is coming, or
why something changed, that is the place to look.

Problem reports benefit from the logs the unit can produce for you; see
[Downloading Logs](maintenance.md#downloading-logs).

## About This Manual

This guide is community documentation, maintained against current software rather than against the
unit's original release. It is written in the open — corrections and additions are welcome through
the [project repository](https://github.com/htp1-app/htp1-docs).
