# Welcome

The Monolith™ HTP-1 is an "AVP," or Audio Video Pre-Processor, designed for use in home theaters. It supports Dolby Atmos®, DTS:X®, Auro-3D®, and Dirac Live®. It features eight HDMI® Ultra High Definition (4K UHD) inputs and two HDMI 4K UHD outputs. It has seven digital audio inputs, two stereo analog inputs, a Mix Out stereo analog output, and sixteen balanced XLR analog outputs.

You configure and control the HTP-1 from a built-in web interface, reachable from a computer, phone, or tablet, or from the included infrared remote control.

## About This Manual

This guide covers firmware **V2.1.2**. It is organized to follow the order of the web interface's sidebar: setup chapters first, then a chapter for each group of settings pages, then reference material at the end.

## What's New in V2.x

If you set up an HTP-1 some time ago, several things have changed:

- **Dirac Live ART** (Active Room Treatment) is supported, alongside the existing Bass Control, Bass Management and Room Correction filter types. See [Dirac Live](dirac.md).
- The front panel touchscreen has been redesigned.
- **Seat Shaker** support adds a dedicated tactile-transducer output with its own content routing, filtering, and presets.
- **Channel Levels** adds a per-channel trim control ahead of tone control, loudness, bass management, and Dirac Live.
- **Peak Monitor** is now its own page, with both a table and a bar-meter view.
- The **Mix Out** output has its own volume and power-on volume, independent of the main volume. It can be used as a dedicated Zone 2 output or as the output for the Seat Shaker, allowing independent level control without affecting the main listening volume.
- A simple mobile remote control app is available at `http://<your-htp1-ip>/remote`.

## Requirements

- The HTP-1 must be connected to an existing Ethernet wired or wireless network for initial configuration. Computers or mobile devices connected to the network can be used to control and configure the HTP-1. The HTP-1 can be operated with no network connection once configuration is complete.
- A separate power amplifier or powered speakers are required.
- A laptop or desktop computer with a web browser. Macs and PCs are supported by the Dirac Live® calibration software.

!!! tip
    A phone can easily access the web interface once the initial setup is complete, but a larger screen is very helpful for setup. The interface also adapts to different screen sizes, although some configuration tasks and detailed edits are much easier to perform on a tablet or desktop than on a phone.

- A USB connected *calibrated* microphone (not included) is required to perform a Dirac Live calibration. For Dirac Live calibration, it is recommended to use the desktop version on a Windows PC or Mac, as it provides features that are not available in the mobile version. The Dirac Live ART upgrade requires its own license, purchased separately through Dirac. The Dirac Live calibration app is downloaded from [dirac.com/resources/downloads](https://www.dirac.com/resources/downloads); the same page lists recommended microphones.
