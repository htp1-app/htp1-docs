# Welcome

The Monolith™ HTP-1 is an "AVP," or Audio Video Pre-Processor, designed for use in home theaters. It supports Dolby Atmos®, DTS:X®, Auro-3D®, and Dirac Live®. It features eight HDMI® Ultra High Definition (4K UHD) inputs and two HDMI 4K UHD outputs. It has seven digital audio inputs, two stereo analog inputs, a Mix Out stereo analog output, and sixteen balanced XLR analog outputs.

You configure and control the HTP-1 from a built-in web interface, reachable from a computer, phone, or tablet, or from the included infrared remote control.

## About This Manual

This guide covers firmware **V2.x**. It is organized to follow the order of the web interface's sidebar: setup chapters first, then a chapter for each group of settings pages, then reference material at the end.

This manual describes the desktop web interface. On smaller screens, some controls may be arranged differently or unavailable because of limited screen space.

## What's New in V2.x

If you last set up your HTP-1 with V1.x firmware, several things have changed:

- **Dirac Live ART** (Active Room Treatment) is supported, alongside the existing Bass Control, Bass Management, and Room Correction filter types. See [Dirac Live](dirac.md).
- The [web interface](product-overview.md#web-interface) has been rewritten with a modern design.
- The [front panel touchscreen](product-overview.md#front-panel-display) has been redesigned.
- [**Seat Shaker**](seat-shaker.md) support adds a dedicated tactile-transducer output with its own content routing, filtering, and presets.
- [**Channel Levels**](channel-levels.md) adds a per-channel trim control ahead of tone controls, loudness, PEQ, bass management, and Dirac Live.
- [**PEQ**](peq.md) can now be placed either before Dirac Live (**Pre**, the default) or after Dirac Live (**Post**).
- [**Peak Monitor**](peak-monitor.md) is now its own page, with both Table and Bars views.
- The [**Mix Out**](home-page.md#mix-out-volume) output has its own volume and power-on volume, independent of the main volume. It can be used as a dedicated Zone 2 output or as the output for the Seat Shaker, allowing independent level control without affecting the main listening volume.
- A simple [mobile remote control](integrations.md#mobile-remote) app is available at `http://<your-htp1-ip>/remote/`.
- V2.x also delivers major improvements to audio processing, calibration, playback reliability, and system control.

## Requirements

- The HTP-1 must be connected to an existing Ethernet wired or wireless network for initial configuration. Computers or mobile devices connected to the network can be used to control and configure the HTP-1. The HTP-1 can be operated with no network connection once configuration is complete.
- A separate power amplifier or powered speakers are required.
- A laptop or desktop computer with a web browser. Macs and PCs are supported by the Dirac Live® calibration software.

- A USB-connected *calibrated* microphone (not included) is required to perform a Dirac Live calibration. Calibration requires the desktop app on a Windows PC or Mac; the mobile app cannot be used with the HTP-1. The Dirac Live ART upgrade requires its own license, purchased separately through Dirac. Download the app from [Dirac’s downloads page](https://www.dirac.com/resources/downloads). See [Dirac’s microphone guidance](https://helpdesk.dirac.com/en/faq/What-microphone-is-required-recommended-for-Dirac-Live-9a3b) for requirements and recommendations.
